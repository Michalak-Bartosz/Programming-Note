# 1. <ins>URI, URL and URN</ins>

* **URI** (Uniform Resource Identifier) is a formal system for uniquely identifying resources and consists of two types: URLs (Uniform Resource Locator) and URNs (Uniform Resource Name).

* **URL** (also known as a web address), identifies a web resource as well as its location on a computer network and how to access it (e.g. http://www.library.pitt.edu).

* **URN** is a formal naming scheme that identifies a resource, but does not indicate its location or how to access it (e.g. ISBN, ISSN).
