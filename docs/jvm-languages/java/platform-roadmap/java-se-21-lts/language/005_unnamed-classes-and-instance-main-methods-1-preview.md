# 1. Unnamed Classes and Instance Main Methods (Preview)

Unnamed classes and instance main methods simplify small Java programs by reducing the ceremony required for an entry point. They are intended to make introductory examples and simple scripts easier to write without removing the full class-based model from the platform.
