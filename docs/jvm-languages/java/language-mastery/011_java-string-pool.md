# 1. Java String Pool

The Java string pool is a memory area used to store literal strings in a way that allows reuse of identical string values. This can reduce memory usage and improve performance in some scenarios by avoiding unnecessary duplicate objects.

Understanding the string pool is useful when reasoning about string equality, memory behavior, and the difference between literal strings and newly created instances.
