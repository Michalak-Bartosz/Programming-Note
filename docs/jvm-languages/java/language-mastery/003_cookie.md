# 1. Cookie

In web applications, a cookie is a small piece of data stored by the browser and sent back to the server with subsequent requests. In Java-based web development, cookies are often used to remember user preferences, session-related information, or lightweight state between requests.

They are simple to use but should be handled carefully because they are client-side data and can be modified by the user. For sensitive information, server-side sessions or secure tokens are usually a better choice.
