# 1. Reflection API

The Reflection API allows a Java program to inspect and sometimes modify classes, methods, fields, and constructors at runtime. It is powerful for frameworks, dependency injection containers, and tooling, but it should be used carefully because it can reduce type safety and make code harder to follow.
