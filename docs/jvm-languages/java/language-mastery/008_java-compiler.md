# 1. Java Compiler

The Java compiler translates Java source code into bytecode that can be executed by the Java Virtual Machine. It serves as the first major step in the Java build pipeline and performs checks for syntax and type correctness.

This process helps developers catch many issues early and produces portable bytecode that can run on any compatible JVM.
