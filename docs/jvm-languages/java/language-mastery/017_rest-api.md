# 1. REST API

REST is an architectural style for designing networked applications, especially web services. In Java, REST APIs are commonly built with frameworks such as Spring Boot, and they rely on standard HTTP methods like GET, POST, PUT, and DELETE to expose resources.

The main idea is to structure services around resources and keep interactions stateless, which makes APIs easier to scale and integrate.
