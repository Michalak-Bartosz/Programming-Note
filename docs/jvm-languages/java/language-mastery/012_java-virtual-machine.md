# 1. Java Virtual Machine (JVM)

The Java Virtual Machine is the runtime environment that executes Java bytecode. It provides memory management, garbage collection, thread execution, and platform independence, which are core reasons Java can run consistently across different operating systems.

A good mental model is that Java source is compiled once into bytecode, and the JVM interprets or JIT-compiles that bytecode for the target machine at runtime.
