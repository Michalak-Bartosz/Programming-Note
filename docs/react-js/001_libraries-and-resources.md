# Libraries and Resources

A curated collection of useful React libraries, tools, and resources for building modern web applications.

## Wave Effects

1. [Create Wavy Background Using CSS & SVG](https://blog.logrocket.com/create-wavy-background-using-css-svg/){ target="_blank" rel="noopener noreferrer" } - Tutorial on creating wavy background effects using CSS and SVG for dynamic visual elements
2. [React Wavify](https://www.npmjs.com/package/react-wavify){ target="_blank" rel="noopener noreferrer" } - React component for creating animated wave effects with customizable colors and animation speed
3. [Knewave Font](https://fonts.google.com/specimen/Knewave?query=wave){ target="_blank" rel="noopener noreferrer" } - Google Fonts typeface with a wavy, playful design perfect for creative projects

## Scroll Effects

1. [React Animate On Scroll](https://www.npmjs.com/package/react-animate-on-scroll){ target="_blank" rel="noopener noreferrer" } - Library for triggering animations as elements scroll into view, with various animation presets
2. [CSS Easing Functions Guide](https://css-tricks.com/ease-out-in-ease-in-out/){ target="_blank" rel="noopener noreferrer" } - Comprehensive guide to understanding and using easing functions for smooth animations
3. [React Scroll Progress Bar](https://www.npmjs.com/package/react-scroll-progress-bar){ target="_blank" rel="noopener noreferrer" } - Component for displaying a progress bar that tracks scroll position on the page

## Menu Components

1. [Building a Draggable Menu in React](https://dev.to/prabhuignoto/building-a-draggable-menu-in-react-5he0){ target="_blank" rel="noopener noreferrer" } - Step-by-step tutorial for creating an interactive draggable floating menu component
2. [React Floating Button Menu](https://www.npmjs.com/package/react-floating-button-menu){ target="_blank" rel="noopener noreferrer" } - Ready-to-use static floating action button menu with expandable options

## Animation Libraries

1. [Framer Motion](https://www.framer.com/motion/){ target="_blank" rel="noopener noreferrer" } - Production-ready motion library for React with declarative animations, gestures, and page transitions

## Timeline Components

1. [React Vertical Timeline Component](https://www.npmjs.com/package/react-vertical-timeline-component){ target="_blank" rel="noopener noreferrer" } - Responsive vertical timeline component for displaying chronological events and milestones

## Carousel Components

1. [React Multi Carousel](https://www.npmjs.com/package/react-multi-carousel){ target="_blank" rel="noopener noreferrer" } - Fully customizable and responsive carousel component with support for multiple items and touch gestures
