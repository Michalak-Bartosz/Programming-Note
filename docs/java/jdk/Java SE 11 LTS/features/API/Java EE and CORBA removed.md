# 1. <ins>Java EE and CORBA removed</ins>

Java EE moved to the Eclipse Foundation with Java 9 under a new name – [Jakarta EE](jakarta-ee.md) (interestingly, still JEE). With Java 9, the modules and classes that were specific to Java EE were deprecated. With Java 11, these deprecated APIs and modules have been removed from the Java SE platform and the JDK. CORBA's APIs were also deprecated in Java 9 and were eventually removed in Java 11.

With Java SE 6 (core Java), you can develop web services using the following technologies:
* JAX-WS (short for Java API for XML-Based Web Services)
* JAXB (short for Java Architecture for XML Binding)
* JAF (short for JavaBeans Activation Framework) 
* Common annotations
